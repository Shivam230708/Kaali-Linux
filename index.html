Instagram Reel Download API

Your ultimate solution to downloading Instagram Reels effortlessly

🔧 How to Use

Simply make a GET request to the following endpoint:

https://instagram-api-botverseravi.gt.tc/api.php?url=REEL_LINK

📥 Example Request

https://instagram-api-botverseravi.gt.tc/api.php?url=https://www.instagram.com/reel/xyz123

📦 Parameters

  • url — (required) The URL of the Instagram Reel you wish to download.
